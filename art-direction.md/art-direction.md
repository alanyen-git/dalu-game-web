# 大陸旅誌｜原創美術設定 v1.0

## 核心視覺

**潮痕行旅**：像一冊被海風翻閱的旅人圖誌。畫面以暖紙、鹽霧青綠與舊銅金描出海岸世界；神祕感來自留白、潮線與鐘聲，不靠大量粒子或高亮魔法光效。整體溫暖、安靜、帶一點未解的異象。所有角色、場景與圖形均為本作原創。

## 色彩與材質

| 用途 | 色彩 | 色碼 |
| --- | --- | --- |
| 墨潮｜標題、深色底 | 深藍綠 | #102C36 |
| 霧港｜主要互動色 | 潮汐青 | #3C8290 |
| 舊銅｜焦點與稀有提示 | 暖金 | #D6A35D |
| 航海紙｜頁面背景 | 淡暖灰米 | #F5F1E8 |
| 手記紙｜卡片背景 | 象牙白 | #FFFDF8 |
| 警示｜危險、損傷 | 暗珊瑚紅 | #A96160 |

材質只用細紙紋、霧面石材、氧化銅和潮濕木頭的輕量暗示；避免金屬鏡面、塑膠漸層與過度發光。狀態不可只靠顏色區分，需搭配文字、圖示或輪廓。

## 形狀與構圖

- 卡片圓角 14–26 px；地圖標記以圓、短線和羅盤刻度組成，不畫仿真遊戲地圖框。
- 主要場景採前景深色剪影、中景城鎮／山脊、遠景霧層三段；保留文字區，不把裝飾壓在標題下。
- 潮線、風向弧線、鐘環是共用紋樣；每頁最多出現一種主紋樣。
- 版面以手機單手操作為先，觸控區至少 44 px，底部安全區留白。

## 角色與生物造型錨點

| 對象 | 輪廓、材質與識別色 |
| --- | --- |
| 洛恩｜流浪劍士 | 斜肩、風磨靛青短斗篷；舊銅扣；劍身有一道像退潮線的淺槽。 |
| 伊妲｜星紋術士 | 窄長剪影、灰紫長衣、星圖玻璃片；符紋像手寫航路，不做整身發光。 |
| 米拉・風泉｜候選英雄 | 米白與青綠旅行披肩、記錄板和摺疊羅盤；輪廓輕快，呼應風泉村。 |
| 鐘影守衛｜Boss | 黑玄武岩外殼、胸前斷裂銅鐘架；縫隙只透低亮潮青，重心穩、中央輪廓明確。 |
| 鹽沼獵犬｜魔物 | 濕灰褐短毛、背脊附鹽晶、琥珀眼；低伏敏捷，避免與溫馴家畜混成同類剪影。 |

這些是後續插畫與像素／向量資產的辨識基準，不代表目前已有完整角色立繪或動畫。

## 場景方向

- 風泉村：淡石牆、風車井、藍綠布棚，屋頂沿坡錯落；光線清爽。
- 霧港村：潮濕木棧、鹽白石階、遠處燈塔，霧層降低對比；保留清楚的碼頭方向。
- 北坡鐘丘：短草、風蝕岩、斷鐘石座；地平線留出鐘聲迴圈的空間。
- 鹽潮荒野：淺水、鹽殼、蘆葦帶；暖灰底色配少量珊瑚紅警示。
- 沉砂遺跡：被流沙切開的幾何石門，銅色刻痕是導航線索，不以血腥裝飾呈現。

## UI 語言與動態

標題用清楚的繁體中文黑體，數值採等寬數字；短標籤不使用全大寫英文。主按鈕為深墨潮底搭暖紙字，選取狀態增加青綠描邊及文字標示，危險動作用暗珊瑚紅。面板像可翻閱的地誌，地圖像疊在紙上的路線卡。轉場以 140–220 ms 淡入／輕移為主；系統遵守 prefers-reduced-motion。動畫只回饋選取、抵達、受擊與存檔，不延遲操作。

## 實作約定

- CSS 語意變數集中於 art-direction.css；新增顏色先對照本表。
- 向量插畫使用 viewBox、少量圖層與本機相對路徑，支援離線快取；不嵌入外部字型或遠端圖檔。
- 每批美術交付需檢查手機亮度下的文字對比、縮放裁切、低動態模式及圖示可辨識性。
- 本版本先建立色彩、角色／魔物造型錨點與第一張海岸向量插畫；完整角色立繪、場景圖集、戰鬥特效與 UI 動畫仍列為後續製作。
